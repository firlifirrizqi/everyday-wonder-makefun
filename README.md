# Everyday Wonder, Two Days to Find the Line

One-sentence entry for the [Make.fun bounty](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) of the same name: a single sentence, at most 200 characters, that makes a small everyday moment strange and new.

## The line

> On the night bus, my reflection rides beside me in the window, getting off at stops I will never visit.

The moment is an ordinary night-bus ride home; the wonder is that the reflection in the window stops being a mirror image and becomes a fellow passenger — one with its own destinations, alighting at stops the rider will never reach.

## How it works

`main.py` writes that single line (103 characters, within the 200-character limit) to `/output/entry.txt`, then re-reads the file and verifies it is one sentence of 1–200 characters, byte-identical to the line. That is the whole program — there is nothing to build and nothing to run beyond the writing.

## Run

```sh
python3 main.py
```
